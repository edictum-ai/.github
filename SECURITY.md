# Security Policy

This policy covers every public repository in the `edictum-ai` organization, unless a repository has its own `SECURITY.md`.

## Reporting a vulnerability

Report privately. Don't open a public issue, pull request or discussion.

- **GitHub:** use "Report a vulnerability" on the repository's Security tab. Private vulnerability reporting is on for every public repository.
- **Email:** [security@edictum.ai](mailto:security@edictum.ai)

Include the affected package and version, what an attacker can do, and the steps to reproduce.

## What happens next

| Stage | Target |
|-------|--------|
| Acknowledgment | 48 hours |
| Triage and severity assessment | 7 days |
| Fix for critical or high severity | Best effort, typically within 30 days |

Fixes ship first. Advisories are published with the fixed release.

## Safe harbor

We consider security research conducted in good faith to be authorized. We will not pursue legal action against researchers who make a good-faith effort to avoid privacy violations, data destruction and service disruption, interact only with accounts they own or have permission to use, and report promptly with enough detail to reproduce.
